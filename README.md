## Start in Codex

Open Codex in the intended project directory and paste:

```text
Adopt https://github.com/edwardansberg/progress-driven-sdlc in this
project. Inspect the current directory, Git boundary, instructions,
and existing work first. Do not silently change the target directory.

Acquire the framework in a separate temporary location, pin one full
commit, and read docs/ops/adopt-framework.md and its required references
from that snapshot. If unavailable, stop without modifying the project.

I authorize local documentation adoption under that procedure, with a
written plan first. Proceed with conflict-free setup; request approval
before replacing existing policy, resolving collisions, or displacing
active work. Preserve project content and Git state. Do not copy upstream
project memory/history, commit, push, install software, or enable automation.

Verify the result and stop for my validation. Keep your briefing short.
```
